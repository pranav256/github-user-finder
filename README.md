# GitHub User Finder

A GitHub profile search tool consuming the official GitHub REST API.

## Features

- **Profile Inspection:** Search any GitHub username to retrieve avatar, bio, follower metrics, public repos, and location.
- **Recent Repositories:** Displays top public repositories sorted by star count and recent updates.
- **Error Handling:** Graceful 404 and rate-limit user feedback.

## Tech Stack

- Vanilla JavaScript (GitHub REST API v3)
- HTML5 & CSS3
